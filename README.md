# My AI Journey

Personal knowledge base documenting my path into AI Automation and Agentic AI, built by Lilia Avagyan.

## About Me

I started my career in customer-facing operations in IT and telecommunications. Working in these environments, I saw firsthand how much time went into repetitive tasks and manual processes. Eventually, I decided to learn how to automate them myself.

Since then, I've built 20+ applications using no-code, low-code, and traditional development tools, including AI travel guides, Telegram bots, and resume analyzers. I completed my Agentic AI course with distinction, presenting three final projects: a job board automation system, a full-stack portfolio platform, and a TravelTech insights dashboard with an AI chatbot. After completing the course, I was personally invited to continue to the advanced program.

That opened the door to more complex, hands-on work: building a tourism booking system from start to client handover, exploring MCP servers and LangGraph agents, and running my own VPS with n8n, Flowise, and Open WebUI.

Currently, I'm working on AI Travel Concierge, an omnichannel automation system using Chatwoot and n8n. Some of my projects are already in use, while others are still evolving.

Here, I share the things I build, the tools I explore, and what I learn along the way.
